# Documentación de gentle-accounts

![Logo de gentle-accounts](../../assets/logo.svg)

Qué encontrará aquí: la guía detallada de gentle-accounts, desde la instalación hasta cómo cambia de cuenta por dentro.

## Qué cubre esta documentación

gentle-accounts mantiene **perfiles** con nombre (por ejemplo `work` y `personal`), cada uno con su propio inicio de sesión de Claude Code y sus propias credenciales de Codex y Anthropic, y permite cambiar entre ellos dentro de Gentle Shell o de pi. El README del repositorio es el resumen corto; estas páginas contienen todos los detalles.
